Relationships:
=============
- Users <-> Roles (Many-to-Many)
- Roles <-> Permissions (Many-to-Many)
- Categories <-> Categories (Self-referencing for subcategories)
- Products -> Brands (Many-to-One)
- Products -> Categories (Many-to-One)
- Products -> Product_Descriptions (One-to-Many)
- Products -> Product_Media (One-to-Many)
- Products -> SKUs (One-to-Many)
- SKUs -> Units (Many-to-Many through SKU_Units)
- SKUs -> Stock_Levels (One-to-Many)
- Warehouses -> Stock_Levels (One-to-Many)
- Warehouses -> Stock_Movements (One-to-Many)
- SKUs -> Stock_Movements (One-to-Many)
- Users -> Carts (One-to-Many)
- Carts -> Cart_Items (One-to-Many)
- Cart_Items -> SKUs (Many-to-One)
- Users -> Orders (One-to-Many)
- Orders -> Order_Items (One-to-Many)
- Order_Items -> SKUs (Many-to-One)
- Orders -> Shipments (One-to-Many)
- Orders -> Order_Events (One-to-Many)
- Orders -> Payments (One-to-Many)
- Payments -> Transactions (One-to-Many)
- Payments -> Refunds (One-to-Many)
- Users -> Sellers (One-to-One)
- Sellers -> Seller_Stores (One-to-Many)
- Sellers -> Seller_Documents (One-to-Many)
- Promotions -> Coupons (One-to-Many)
- Promotions <-> Categories (Many-to-Many)
- Promotions <-> Products (Many-to-Many)
- Users -> Audit_Logs (One-to-Many)
